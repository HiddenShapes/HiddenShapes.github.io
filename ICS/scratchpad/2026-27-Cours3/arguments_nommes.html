Arguments positionnels

On a vu en cours que lors de l’appel d’une fonction, les valeurs des arguments de l’appel sont liées aux paramètres de la fonction dans l’ordre où les paramètres sont définis. On dit que dans cet appel, les arguments sont positionnels.

import math

def vol_cylindre(h, r):
    print("je calcule le volume d'un cylindre de rayon", r, "et hauteur", h)
    return math.pi * r**2 * h

print(vol_cylindre(3, 5))
print(vol_cylindre(5, 3))
je calcule le volume d'un cylindre de rayon 5 et hauteur 3
235.61944901923448
je calcule le volume d'un cylindre de rayon 3 et hauteur 5
141.3716694115407

Les deux appels ne donnent pas le même résultat : dans le premier, h vaut 3 et r vaut 5, dans le second c’est l’inverse.

Arguments nommés

Cependant, on peut, dans l’appel de la fonction, lier explicitement un argument à un paramètre, et ceci dans n’importe quel ordre. On parle d’arguments nommés.

print(vol_cylindre(r = 3, h = 5))
print("\n**************\n")
print(vol_cylindre(h = 3, r = 5))
je calcule le volume d'un cylindre de rayon 3 et hauteur 5
141.3716694115407

**************

je calcule le volume d'un cylindre de rayon 5 et hauteur 3
235.61944901923448

Cela rend le code plus lisible : lorsqu’on lit la portion de code où se fait l’appel à vol_cylindre, on sait tout de suite quelles valeurs correspondent respectivement au rayon et à la hauteur, sans devoir aller vérifier la définition de la fonction.

Mélanger arguments positionnels et nommés

On peut aussi, dans l’appel de la fonction, nommer explicitement certains arguments mais pas tous (toujours pour des raisons de lisibilité). Mais dans ce cas, les arguments nommés doivent apparaître après tous les arguments positionnels.

from math import sqrt

def moyenne(x, y, alg):
    '''
    Entrée: x et y nombres positifs, alg booléen
    calcule la moyenne algébrique de x et y si alg = True
    sinon calcule la moyenne géométrique
    '''

    if alg:
        return (x + y)/2

    else:
        return sqrt(x * y)

print(moyenne(2, 1, True))
print(moyenne(2, 1, False))

print("\n********************\n")

print(moyenne(2, 1, alg = True))
print(moyenne(2, 1, alg = False))

print("\n********************\n")

print(moyenne(x = 2, y = 1, alg = True))
print(moyenne(2, y = 1, alg = False))
1.5
1.4142135623730951

********************

1.5
1.4142135623730951

********************

1.5
1.4142135623730951

Que se passe-t-il si un argument nommé apparaît avant un argument positionnel ? Python refuse même de lire le programme :

print(moyenne(x = 2, 1, alg = True))
  Cell In[4], line 1
    print(moyenne(x = 2, 1, alg = True))
                                      ^
SyntaxError: positional argument follows keyword argument

Deux distinctions à ne pas confondre

Avoir deux genres de paramètres, obligatoire ou par défaut, et avoir deux genres d’arguments, positionnels ou nommés, sont en principe deux choses différentes, qui ne sont pas mutuellement exclusives.

from math import sqrt

def moyenne(x, y, alg = True):
    if alg:
        return (x + y)/2

    else:
        return sqrt(x * y)

print(moyenne(2, 1, alg = True))
print(moyenne(2, 1, False))
print(moyenne(2, 1))
1.5
1.4142135623730951
1.5

Le paramètre alg est optionnel, et pourtant on peut lui fournir un argument aussi bien positionnel que nommé.

Quand nommer devient obligatoire

Par contre, il y a un cas où le fait d’avoir un paramètre optionnel nous oblige, dans l’appel, à nommer l’argument correspondant : c’est lorsqu’on a une fonction avec un nombre variable d’arguments et un paramètre optionnel. Dans ce cas, si on veut fournir un argument correspondant au paramètre optionnel, il faut le nommer pour éviter l’ambiguité :

def f(*nombres, somme_ou_produit = 0):
    '''
    prend un nombre variable d'arguments
    calcule leur somme si somme_ou_produit vaut 0
    et leur produit si somme_ou_produit = 1
    '''
    if somme_ou_produit == 0:
        # je calcule la somme des éléments du tuple nombres
        result = 0
        for x in nombres:
            result += x
    else:
        # je calcule le produit des éléments du tuple nombres
        result = 1
        for x in nombres:
            result *= x

    return result

# cet appel calcule la somme de 3, 4, 5, et 1
# si on pensait calculer le produit de 3, 4, et 5, c'est raté!
print(f(3, 4, 5, 1))

# là, en nommant le dernier argument, on indique que c'est
# l'argument lié au paramètre optionnel et pas un élément
# additionnel du tuple nombres
print(f(3, 4, 5, somme_ou_produit = 1))
13
60

C’est pour cela que lorsqu’on veut modifier les valeurs par défaut des paramètres end et sep de la fonction print (qui prend un nombre variable d’arguments), on doit les nommer dans l’appel (on doit les nommer en tout cas, parce qu’il y en a deux. Mais même si print admettait un seul paramètre optionnel, on aurait dû aussi le nommer).
