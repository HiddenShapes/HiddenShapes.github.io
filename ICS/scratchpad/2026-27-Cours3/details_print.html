Utilisation de base

print peut afficher des chaînes de caractères, des nombres et des expressions :

print('Bonjour le monde !')      # un str
print(42)                        # un int
print(3.14)                      # un float
print('Résultat :', 2 + 3)       # plusieurs arguments
Bonjour le monde !
42
3.14
Résultat : 5

Caractères d’échappement

Les str en Python sont délimitées par des guillemets simples (') ou doubles ("). Mais que se passe-t-il si on veut inclure un guillemet à l’intérieur du str lui-même ?

print('l'homme')   # erreur : Python croit que le str se termine au deuxième guillemet
  Cell In[2], line 1
    print('l'homme')   # erreur : Python croit que le str se termine au deuxième guillemet
                  ^
SyntaxError: unterminated string literal (detected at line 1)

Le même problème se pose avec d’autres caractères qui ont une signification spéciale pour Python, comme le backslash \.

Pour résoudre ça, on échappe le caractère problématique : on le fait précéder d’un backslash \, ce qui indique à Python de le traiter comme un caractère ordinaire, et non comme un signal. C’est ce qu’on appelle un caractère d’échappement.

Les caractères d’échappement commencent par un backslash (\) et permettent d’inclure des caractères spéciaux dans les chaînes :

Séquence Effet Exemple
\n Nouvelle ligne print('A\nB')
\t Tabulation print('X\tY')
\\ Backslash littéral print('C:\\Users')
\' Guillemet simple print('l\'homme')
\" Guillemet double print("il dit \"oui\"") 
print('Première ligne\nDeuxième ligne')
print('Nom:\tJean\nÂge:\t25')
print('Il a dit : \'Bonjour !\'')
print("Il a dit : 'Bonjour !'")    # pas besoin de \ ici
Première ligne
Deuxième ligne
Nom:    Jean
Âge:    25
Il a dit : 'Bonjour !'
Il a dit : 'Bonjour !'

Remarque. Si la chaîne ne contient que des guillemets simples, on peut utiliser des guillemets doubles pour la délimiter (et inversement), évitant ainsi le besoin d’échapper.

Le paramètre end

Par défaut, chaque appel à print ajoute '\n' à la fin. Le paramètre end permet de changer ce comportement :

print('Première ligne')
print('Deuxième ligne')
print('---')
print('Sans nouvelle ligne', end=' ')
print('suite sur la même ligne')
print('Avec un point', end='.')
print(' Fin')
Première ligne
Deuxième ligne
---
Sans nouvelle ligne suite sur la même ligne
Avec un point. Fin

Remarque. end='' (chaîne vide) permet de ne rien ajouter à la fin, ce qui est utile pour construire une sortie caractère par caractère.

Le paramètre sep

Quand print reçoit plusieurs arguments, il les sépare par un espace par défaut. Le paramètre sep permet de personnaliser ce séparateur :

print('a', 'b', 'c')              # séparateur par défaut
print('a', 'b', 'c', sep='-')
print('a', 'b', 'c', sep=' | ')
print('Bond', 'James Bond', sep=', ')
print(2024, 12, 25, sep='/')
a b c
a-b-c
a | b | c
Bond, James Bond
2024/12/25

Formatage avec les f-strings

Hors programme. Cette section et la suivante sont fournies à titre indicatif uniquement. Leur contenu ne sera pas demandé à l’examen.

Les f-strings (formatted string literals) permettent d’insérer des variables et des expressions directement dans une chaîne en les plaçant entre accolades {} :

nom = 'Alice'
age = 25
print(f'Bonjour {nom}, tu as {age} ans')

base = 5
hauteur = 3
aire = base * hauteur / 2
print(f'Triangle: base={base}, hauteur={hauteur}')
print(f'Aire = {aire}')
Bonjour Alice, tu as 25 ans
Triangle: base=5, hauteur=3
Aire = 7.5

Formatage numérique

On peut contrôler l’affichage des nombres avec des spécificateurs de format après : :

Syntaxe Effet Exemple
{x:.2f} 2 décimales 3.14
{x:.4f} 4 décimales 3.1416
{x:,} Séparateur de milliers 1,234,567
{x:.1%} Pourcentage 75.0%
{x:>10} Aligné à droite (10 car.) hello
{x:0>5} Zéros à gauche 00042 
pi = 3.14159265
print(f'Pi avec 2 décimales: {pi:.2f}')
print(f'Pi avec 4 décimales: {pi:.4f}')

grand_nombre = 1234567
print(f'Avec séparateurs: {grand_nombre:,}')
print(f'En pourcentage: {0.75:.1%}')
Pi avec 2 décimales: 3.14
Pi avec 4 décimales: 3.1416
Avec séparateurs: 1,234,567
En pourcentage: 75.0%

Résumé

Un appel avec tous les arguments à imprimer ressemble à ceci :

print(objet_1, objet_2, ..., sep=' ', end='\n', file=sys.stdout)

Paramètres.

  • objet_1, objet_2, ... : Un ou plusieurs objets à afficher, séparés par des virgules.
  • sep : Le séparateur inséré entre les objets (par défaut : un espace ' ').
  • end : Le caractère ajouté après le dernier objet (par défaut : une nouvelle ligne '\n').
  • file : Le flux de sortie (par défaut : la console).
Ce que je veux faire Comment
Afficher du texte print('texte')
Afficher plusieurs valeurs print(a, b, c)
Changer le séparateur print(a, b, sep='-')
Rester sur la même ligne print(x, end='')
Insérer une variable dans du texte print(f'val = {x}')
Formater un nombre print(f'{pi:.2f}')
Nouvelle ligne dans une chaîne '\n'
Tabulation dans une chaîne '\t'
